Developer guide

Supported features and document compatibility

Use this reference to assess viewing, authoring, Word exchange and export for your documents. Support depends on the operation and content, not only the file extension.

Input and output formats

OperationScope
OpenDOCX, DOCM, DOTX and DOTM packages. VBA/macros are not executed.
Edit and saveSupported DOCX authoring and serialization. Unlock password-protected files or convert older DOC/DOT/RTF files before opening. PDF is an output format, not an input editor.
GenerateReusable DOCX templates. Convert DOTX/DOTM templates to DOCX for generation.
ExportDOCX; browser/server PDF and page images. Font availability affects layout across environments.

Rendering an imported object does not imply support for every editing operation on that object. Saving preserves unrelated package content; this is not a promise of arbitrary Word feature parity.

PDF and accessibility

PDF includes searchable text, links, bookmarks and supported tagged headings, lists, tables and figures. Supported graphics use vectors. Visible native text and complex effects use raster layers, so DPI affects sharpness, output size and memory.

Tagged structure is not PDF/UA certification or a guarantee for every screen reader. Evaluate reading order, descriptions, contrast and your target readers. See PDF export.

Browser and host requirements

Ordinary browser viewing/editing works without a rendering server. Supply document fonts for consistent results and deploy required chunks. Browser security policies affect clipboard, screen capture and voices. Node analysis and generation need no browser; server layout/PDF need Chrome or Chromium and playwright-core.

Your application provides storage, authentication and permissions. Collaboration and Agent require their own host services. See deployment choices.

Evaluate a representative workflow

Open your document, edit the structures your users need, exercise Undo/Redo, save DOCX, reopen it, and inspect PDF output. Check important exchanges in Word or LibreOffice with the same fonts. Try the editor and report a minimal reproduction if a required operation differs.

For upgrade changes, see release notes. This reference describes the current documented behavior; it is not a certification of every document or browser.
