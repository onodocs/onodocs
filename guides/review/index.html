Use the review workflow

Open the agreement review demo, select a clause and add a comment. Switch the demonstration reviewer identity to reply, suggest replacement wording, then accept or reject individual changes or the full replacement. Compare with the original or a saved version.

Download reviewed Word to retain comments, replies and pending supported revisions. Open returned Word to continue the review. Saved demo versions exist only in the current tab; download before closing.

Connect editor and document review

Use editor.review(command) for review actions participating in editor history and change events. Use document.readReview() to inspect comments, revisions and tracking state. Headless workflows can call document.review(command) directly; those operations do not supply a UI history or persistence service.

const state = await editor.document.readReview();
console.log(state.comments, state.revisions);
const bytes = await editor.save();
await saveReviewedDocument(bytes);

The editor must have an open document. Your callback stores its bytes. See review and comparison contracts for command types and observed change results. Configure application sessions when saves belong to an application record.

Own identity and permissions

A reviewer selector in a sample is not authentication. Your application supplies trusted identities and decides who may edit, comment or decide revisions. For shared review, use the collaboration service; it derives review authors from authenticated roles.

Separate comments from approvals or signatures in your own business process. Preserve original and reviewed files when your workflow needs an audit trail.

Check Word exchange

Tracked text replacements stay within a paragraph. Disable tracking for structural edits. Imported paragraph-mark and table-row revision decisions require Word. Test comments, replies, suggested text and save/reopen with the Word versions used by your reviewers.

Comparison reports differences between snapshots; it is not shared editing or a general document merge service. See compatibility for other limits.
