Extract text and tables from DOCX in JavaScript and TypeScript

Turn Word content into plain text and JSON for search, application records or AI input. Use the same typed query API in the browser and Node.js, without rendering pages or starting a headless browser.

Read plain text and typed paragraphs

Open a browser File, an ArrayBuffer or a Uint8Array. Query the document’s text and structure without a canvas, fonts or page layout.

import { openDocument } from "@onodocs/sdk";

const doc = await openDocument(file);
const body = doc.query.stories().where({ story: "body" });
const text = body.map(story => story.text).join("\n");
const paragraphs = body.paragraphs().map(paragraph => ({
  text: paragraph.text,
  style: paragraph.style
}));

file is the selected browser File. The complete file picker appears below. Paragraph text joins its runs, so formatting changes do not split a sentence into separate records. Paragraph queries include paragraphs inside tables and content controls.

Body text includes table-cell text, so appending the tables would duplicate it. Plain text preserves imported text and paragraph boundaries, not the page layout.

Extract tables as arrays of rows and cells

const tables = body.tables().map(table => table.textRows);

The result is an array of tables containing rows of cell strings. textRows includes the first row. It does not guess whether that row contains headers or convert dates, numbers or currencies. Convert those values in your application if needed.

For structural access, use table.rows, row.cells and each cell's children. A merged or nested table is not necessarily a rectangular spreadsheet. textRows lists the imported cells without repeating values across merged spans. Nested table text can occur inside an outer cell, while tables() also returns nested tables. Choose the level your application needs before flattening.

Find a table by its headers and map rows to JSON

The sample brief uses the first-row labels Deliverable, Owner and Due. Match those labels in their exact order, then remove the header row and map the remaining cells:

const matches = body.tables().where({
  headers: ["Deliverable", "Owner", "Due"]
});
const deliveryTables = matches.map(table =>
  table.textRows.slice(1).map(([deliverable = "", owner = "", due = ""]) => ({
    deliverable, owner, due
  }))
);

Header matching compares the complete first row, including case and whitespace. It does not search later rows or infer synonyms.

The output contains one entry per matching table, or [] if none match. Use one() only when exactly one match is required; it throws for zero or multiple results. optional() allows zero but still throws for multiple matches.

This record mapping is for the simple three-column sample. Missing cells become empty strings. Additional cells remain available in the raw table output. Validate required values, merged cells and date formats in your application before importing records. Due dates remain as written, such as “Nov 04”. The sample does not infer a year.

The complete browser extraction sample

The browser and Node.js samples use the function below to select text and fields for JSON output. Query objects contain parent links and source metadata, so select the values you need instead of serializing the full objects.

extract.ts · typed extraction function
import type { InspectedDocument } from "@onodocs/sdk";

export function extractContent(doc: InspectedDocument) {
  const body = doc.query.stories().where({ story: "body" });
  const tables = body.tables();
  return {
    text: body.map(story => story.text).join("\n"),
    paragraphs: body.paragraphs().map(paragraph => ({ text: paragraph.text, style: paragraph.style })),
    tables: tables.map(table => table.textRows),
    deliveryTables: tables.where({ headers: ["Deliverable", "Owner", "Due"] }).map(table =>
      table.textRows.slice(1).map(([deliverable = "", owner = "", due = ""]) => ({ deliverable, owner, due }))
    )
  };
}

main.ts · local files, cancellation, copy and download
import { openDocument } from "@onodocs/sdk";
import { extractContent } from "./extract.ts";
import sample from "../view-document/sample.docx";

const status = document.querySelector<HTMLOutputElement>("#status")!;
const file = document.querySelector<HTMLInputElement>("#file")!;
const format = document.querySelector<HTMLSelectElement>("#format")!;
const output = document.querySelector<HTMLTextAreaElement>("#output")!;
const cancel = document.querySelector<HTMLButtonElement>("#cancel")!;
const copy = document.querySelector<HTMLButtonElement>("#copy")!;
const download = document.querySelector<HTMLButtonElement>("#download")!;
let controller: AbortController | undefined;
let content: ReturnType<typeof extractContent> | undefined;

function showOutput() {
  output.value = !content ? "" : format.value === "text" ? content.text : JSON.stringify(format.value === "tables" ? content.tables : content.deliveryTables, null, 2);
}

async function open(source: File | Uint8Array) {
  controller?.abort();
  controller = new AbortController();
  const { signal } = controller;
  content = undefined;
  showOutput();
  copy.disabled = download.disabled = true;
  cancel.disabled = false;
  status.textContent = "Extracting document…";
  try {
    const doc = await openDocument(source, { signal });
    if (signal.aborted) return;
    content = extractContent(doc);
    showOutput();
    copy.disabled = download.disabled = false;
    status.textContent = `Ready · ${content.paragraphs.length} body ${content.paragraphs.length === 1 ? "paragraph" : "paragraphs"} · ${content.tables.length} ${content.tables.length === 1 ? "table" : "tables"} · ${content.deliveryTables.length} delivery ${content.deliveryTables.length === 1 ? "table" : "tables"}. Your file and extracted content stay in this browser.`;
  } catch (error) {
    if (!signal.aborted) status.textContent = `Unable to extract document. ${error instanceof Error ? error.message : "Try another Word file."}`;
  } finally {
    if (!signal.aborted) cancel.disabled = true;
  }
}

file.addEventListener("change", () => {
  const selected = file.files?.[0];
  file.value = "";
  if (selected) void open(selected);
});
document.querySelector("#sample")!.addEventListener("click", () => { void open(sample); });
format.addEventListener("change", showOutput);
cancel.addEventListener("click", () => {
  controller?.abort();
  cancel.disabled = true;
  status.textContent = "Extraction cancelled. Choose another file or open the sample.";
});
copy.addEventListener("click", async () => {
  try {
    await navigator.clipboard.writeText(output.value);
    status.textContent = "Output copied.";
  } catch {
    output.focus();
    output.select();
    status.textContent = "The output is selected. Press Ctrl+C or Command+C to copy it.";
  }
});
download.addEventListener("click", () => {
  const plain = format.value === "text";
  const url = URL.createObjectURL(new Blob([output.value], { type: plain ? "text/plain;charset=utf-8" : "application/json" }));
  const link = document.createElement("a");
  link.href = url;
  link.download = plain ? "document-text.txt" : `${format.value}.json`;
  link.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
});
window.addEventListener("pagehide", event => { if (!event.persisted) { controller?.abort(); content = undefined; } });
void open(sample);

The build embeds ../view-document/sample.docx using its DOCX binary loader. Clone the repository to run this example. Applications that open only local files need no DOCX loader. Opening a replacement aborts the previous operation and clears its output. Failed loads leave copy/download disabled until another document succeeds.

Unlike the rendering document, this inspected document has no dispose() method. Release references when finished. There are no views or page canvases to dispose. Cancellation uses AbortSignal. A synchronous step can finish before cancellation takes effect. Large document models and JSON output still take memory and processing time.

Extract DOCX content in Node.js without a browser

The same analysis entry point accepts a Node Buffer, which is a Uint8Array. This command uses the same extraction function and writes JSON to standard output. It prints its source-code link to standard error so you can redirect the JSON output to a file.

node.ts · complete Node.js command
import { readFile } from "node:fs/promises";
import { openDocument } from "@onodocs/sdk";
import { extractContent } from "./extract.ts";

const bytes = await readFile(process.argv[2] ?? new URL("../view-document/sample.docx", import.meta.url));
const doc = await openDocument(bytes);
console.log(JSON.stringify(extractContent(doc), null, 2));
console.error("Sample source: https://github.com/onodocs/onodocs/tree/main/examples/docx-extraction");

Scope stories and search paragraph text

Body, headers, footers, notes and textboxes are separate stories. Query them deliberately when defining the contents of an export. A header story contains the header once, even when it repeats on several pages.

const headers = doc.query.stories().where({ story: "header" })
  .paragraphs().map(paragraph => paragraph.text);

const matches = body.findText(/launch/gi).map(range => ({
  text: range.text,
  paragraph: range.paragraph.text,
  start: range.start,
  end: range.end
}));

Search returns paragraph-local ranges and can span formatting runs within one paragraph, but not paragraph boundaries. Offsets follow JavaScript UTF-16 string indexing and the end offset is exclusive. See the query API, element types, and text ranges.

Extraction limits, privacy and licensing

Extraction reads supported Word text and structure. It does not recognize text inside images or preserve the full OOXML. Floating objects and page columns can appear in a different order from the rendered page. Extraction does not preserve styling or exact pagination, and it does not recalculate every Word field.

Supported packages include DOCX, DOCM, DOTX and DOTM. Macros are not executed. Password-protected files and older DOC, DOT or RTF files must be unlocked or converted first. General Word editing and saving changes back to DOCX are not supported.

The browser sample does not send document contents, filenames, extracted values or analytics. The initial load downloads application assets. Extraction, copying and downloading then run locally. Nothing is sent to an AI model. If your application later sends extracted content elsewhere, that is a separate data-handling decision.

Evaluation is registration-free and exposes the complete query API. The rendering watermark does not get inserted into extracted text. Production use requires a commercial SDK license. Signed keys are verified offline. Sample code, guides and authored documents are MIT-licensed, while the SDK is separately licensed.
