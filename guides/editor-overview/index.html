OnoDocs Editor

A customizable Word editor for your application

Open, edit and save Word documents in your browser application. Use the ready-made interface, configure its controls, or adapt the public MIT-licensed Editor source.

Work with the document

Make it fit your application

Choose commands, fonts, styles and permitted modes. Add application actions to the ribbon, theme the interface with CSS properties, and connect your own saving or writing services. The document operations remain available through the same public SDK.

The complete Editor source and independent build are public. You can maintain a customized package without a private engine checkout. Start with configuration and extension points, then use the source build guide when you need deeper changes.

Embed it

npm install @onodocs/editor
import { createEditor } from "@onodocs/editor";
const editor = createEditor({ container: document.querySelector("#editor") });
await editor.newDocument();

Give #editor an empty host with a usable height and bundle this module for the browser. Call editor.dispose() on unmount. The complete JavaScript guide covers errors, document replacement and acknowledged storage; the React and Next.js guide includes a working application.

Add document assistance

The optional Agent answers questions, locates passages and makes requested changes through public document APIs. It uses your model backend and participates in editor history. Review changes and use Undo when needed.

Model requests send relevant context to the configured provider. Keep credentials on your backend and control access and usage in your application. Add the document Agent.
