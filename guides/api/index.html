openDocument

Import the analysis or browser version according to the capabilities needed.

openDocument(input: ArrayBuffer | Uint8Array | Blob, options?: OpenDocumentOptions): Promise<InspectedDocument>
openDocument(input: ArrayBuffer | Uint8Array | Blob, options?: BrowserOptions): Promise<BrowserDocument>

Both entry points accept DOCX, DOCM, DOTX and DOTM inputs, including File, which extends Blob. Macro content is not executed. Opening copies byte inputs; File/Blob input is read once. Fetch URLs in application code before opening.

OptionTypeMeaning
signalAbortSignalCancel opening.
revisionView"accepted" | "original" | "markup"Select the document revision view.
licenseKeystringOffline trial or commercial token. Omit for evaluation.
fontsFontSourcesBrowser/server only. Additional font sources; see font options.
defaultFontstringBrowser/server only. Default font family.
containerHTMLElementBrowser only. Mount provisional pages while loading.
viewOptionsViewOptionsInitial zoom, page gap and title for the mounted view.
onProgress(progress: DocumentProgress) => voidObserve parsing, fonts, layout and ready stages, current pages and mounted view.

Opening rejects on failure or cancellation. Analysis does not create pages or require disposal. See the guide’s shared error and cleanup pattern.

Document objects

DocumentProgress contains stage (parsing, fonts, layout or ready), pages and optional view. Layout events may also supply phase, iteration, completed and total; these describe the current phase, not an overall percentage. Preview pages can change until opening completes.

Document elements

All elements expose readonly kind, id, text, source, children, and parent (undefined at the root). Source locations may be undefined; when present they contain factIndex, ordinal (bigint), and provenance.

Kind / typeAdditional members
document / DocumentRootRoot node.
story / DocumentStorystory, scopeId
paragraph / DocumentParagraphnodeId, style: string | null
run / DocumentRunnodeId, semantic, link: DocumentLink | undefined
table / DocumentTablesemantic, rows: readonly DocumentRow[], textRows: readonly (readonly string[])[]
row / DocumentRowsemantic, cells: readonly DocumentCell[], parent: DocumentTable
cell / DocumentCellsemantic, parent: DocumentRow
contentControl / DocumentContentControlnodeId, tag: string | null, title: string | null
bookmark / DocumentBookmarkname, run (start target, not an enclosing range).

textRows includes the first row. Nested-table text stays within its containing cell; merged cells retain authored topology, so rows are not padded into a rectangular grid. A reused header is one semantic story with multiple physical occurrences.

A run’s link is { kind: "external", target, tooltip } or { kind: "bookmark", target }. The target is a URL or bookmark name. Applications own link navigation. Elements contain parent references and bigint metadata; use map to project text and selected fields into JSON.

DocumentTextRange

interface DocumentTextRange {
  readonly kind: "textRange";
  readonly paragraph: DocumentParagraph;
  readonly start: number;
  readonly end: number;
  readonly text: string;
}

findText searches contiguous text across runs within a paragraph. Ranges use half-open [start, end) JavaScript UTF-16 offsets. String searches are case sensitive. Regular expressions preserve flags, do not alter the caller’s lastIndex, and omit zero-length matches. Each selected contiguous interval is searched independently. Searches do not join paragraphs or read text inside raster images. Semantic text may differ from generated field appearances after layout.

Text updates

update(updates: DocumentTextUpdate | readonly DocumentTextUpdate[], options?: { signal?: AbortSignal }): Promise<void>

interface DocumentTextUpdate {
  readonly target: string | DocumentEditableElement | DocumentTextRange;
  readonly text: string;
}

Available on inspected, browser, and server documents. The target is a run, paragraph, cell, content control, its query ID, or a search range. DocumentEditableElement is the union of those four element types. Element targets must contain ordinary text in one paragraph. Text inherits the first selected run’s formatting. Tabs and newlines are supported. Range replacements preserve text outside the range and its formatting; an empty range inserts text. Offsets use the original paragraph’s UTF-16 positions and cannot split surrogate pairs.

const customer = doc.query.contentControls().where({ tag: "customer" }).one();
await doc.update({ target: customer, text: "Willow Design" });

Batches reject overlapping or missing targets, generated fields, and multi-paragraph replacements without changing document content. Disjoint ranges in one run can be updated together. Unchanged updates preserve snapshots, formatting, and attachments. Updates execute in submission order. Browser updates rebuild layout and refresh views; existing HTML attachments are removed and can be reattached with fresh anchors.

For server updates, obtain target elements, IDs, or ranges by inspecting the same input with the analysis entry point. Exported page images and PDFs reflect updates. Saving a modified Word file, structural editing, and field recalculation are unsupported.

DocumentView

doc.mount(container: HTMLElement, options?: ViewOptions): DocumentView

interface ViewOptions {
  readonly zoom?: number | "fit-width";
  readonly gap?: number;
  readonly title?: string;
}

zoom is a numeric scale or fit-width. Scale 1 uses 96 CSS pixels per inch; fit-width tracks the container. gap is the gap between page shells in CSS pixels, not twips. title labels the view.

MemberReturn value / meaning
elementHTMLElement; the view’s DOM root.
disposedboolean
whenRendered()Promise<void>; wait for the visible neighborhood to finish painting.
setZoom(zoom)void; accepts a number or "fit-width".
toClient(pageIndex, point)DocumentPoint; page twips to viewport CSS pixels.
fromClient(point){ pageIndex, point } | undefined; viewport CSS pixels to page twips.
hitTest(point)DocumentHit | undefined; accepts viewport CSS pixels.
scrollTo(anchor, options?)boolean; reveal the first fragment of a ViewAnchor. Options use native ScrollIntoViewOptions. Returns false if no fragment exists.
attach(element, options)DocumentAttachment; see attachments.
dispose()void; remove this view and its attachments.

DocumentPoint is { x: number, y: number }. Points passed to view hit testing and fromClient use the same coordinate system as event.clientX/clientY.

HTML attachments

view.attach(element: HTMLElement, options: AttachmentOptions): DocumentAttachment
OptionType / meaning
anchor (required)ViewAnchor: DocumentElement, DocumentTextRange, DocumentFragment, or DocumentPage
placement"overlay" (default), inside-{top|center|bottom}-{left|center|right}, or outside-{top|right|bottom|left}.
size{ width: number, height: number } in twips. Omit to fill the anchor, reduced by inside inset.
offset{ x: number, y: number } in twips, applied after placement.
insetInside placement only. Inward spacing in twips.
gapOutside placement only. Distance from the selected edge in twips; the control is centered along that edge.

Content with multiple visible fragments requires explicit selection through doc.geometry.fragments(anchor). Content anchors preserve transforms and clipping; page anchors use the full page. Attachments follow zoom and resize but do not reflow text.

Attaching moves the HTML element into the view. Use a dedicated element or a framework portal. DocumentAttachment.element returns that element; disposed reports its state; dispose() removes it and restores its original inline style. Reattaching the same HTML element disposes its previous attachment, including in another view. Application inputs do not change document text or appear in exported images.

Geometry and hit testing

MethodReturn value
doc.geometry.fragments(anchor)readonly DocumentFragment[]; anchor is a DocumentElement or DocumentTextRange.
doc.geometry.hitTest(pageIndex, point)DocumentHit | undefined; point uses page twips.

A fragment contains pageIndex, rectangle, transform, bounds, and clips. Bounds enclose the unclipped geometry; retain the supplied transforms and clips when interpreting a fragment. Content may span lines, pages, or repeated stories. Row fragments cover the row’s own cells as one rectangle per physical occurrence.

interface DocumentHit {
  readonly element: DocumentElement;
  readonly fragment: DocumentFragment;
  readonly caret?: {
    readonly paragraph: DocumentParagraph;
    readonly offset: number;
    readonly point: DocumentPoint;
  };
}
const hit = view.hitTest({ x: event.clientX, y: event.clientY });
if (hit) {
  const cell = doc.query.within(hit.element).closest("cell").optional();
}

The element is the actual object from the current query snapshot. Text hits resolve to a run or paragraph; table whitespace resolves to a cell or table. The optional caret uses the same UTF-16 offsets as text queries. Generated field appearances omit a caret when no source position can be represented. Raster drawings without a semantic hit identity and blank page space return no element. Invalid page indices throw.

RenderPageOptions

OptionType / meaning
format"png" | "jpeg"; default PNG.
dpiPositive finite output resolution; default 96 DPI.

PDF output defaults to 150 DPI. PDF exports contain page images at the document’s physical sizes, including mixed sizes. They have no selectable text or tagged-PDF accessibility. HTML attachments are excluded.

Document contexts make no outbound requests. Supply fonts as data URLs or install them on the rendering host. Cancelling an executing operation closes the document context; reopen it to retry. Cancelling a queued operation leaves the active operation and document intact. Operations on one document are serialized; your application controls concurrency across documents. Dispose documents and the renderer in finally blocks in production.

FontSources

type FontSources = string | FontVariantSources | Readonly<Record<string, string | FontVariantSources>>;

interface FontVariantSources {
  readonly regular: string;
  readonly bold?: string;
  readonly italic?: string;
  readonly boldItalic?: string;
  readonly collectionIndex?: number | Readonly<Partial<Record<"regular" | "bold" | "italic" | "boldItalic", number>>>;
  readonly fallbackFaces?: readonly string[];
  readonly familyFaces?: Readonly<Partial<Record<"roman" | "swiss", string>>>;
}

Strings identify font sources. Use a family-name map to provide multiple families and variant objects for their faces. Embedded DOCX fonts load automatically. See the guide’s font deployment notes.

LicenseStatus

Pass licenseKey when opening a document. Browser/analysis documents expose license; server documents expose asynchronous licenseStatus(). Verification is offline; browser verification requires HTTPS or a secure local context.

modeAdditional property
"evaluation"reason: missing-key, invalid-key, verification-unavailable, not-yet-valid, trial-expired, release-not-covered, demo-expired, or origin-not-covered.
"trial"license: signed trial claims.
"demo"license: a website demonstration token valid for at most 24 hours at its exact browser origin.
"commercial"license: signed commercial claims.

Evaluation keeps analysis results available and watermarks rendered output. sdkReleaseDate is the SDK’s exported release-date string. See licensing terms.

Low-level models and stages

The default entry point also re-exports the engine’s stage APIs and readonly contracts. These are for applications that provide their own services or need an intermediate result.

APIPurpose

Use openDocument for managed loading and rendering. Stage outputs must not be mutated, and layout owns physical geometry. The complete low-level signatures are included in the package’s TypeScript declarations; see the core exports.
