Open and inspect

Use the default entry for data operations in Node or a browser. content and body are live query roots; snapshot() captures a query at a point in time. Returned elements and subqueries are snapshots. Dispose documents after use.

Query document content

Queries select document elements and expose search ranges. Paragraph styleId identifies its authored style; properties distinguishes authored overrides from effective values. Reacquire targets after edits.

Import from @onodocs/sdk.

DocumentQuery
export interface DocumentQuery<K extends DocumentElementKind = DocumentElementKind> extends QueryResults<ElementOf<K>> {
    /** Selected ranges joined with newlines; empty paragraphs contribute empty ranges. */
    readonly text: string;
    noteSettings(this: DocumentQuery<"document">): QueryResults<DocumentNoteSettings>;
    sections(this: DocumentQuery<"document">): QueryResults<DocumentSection>;
    get(this: DocumentQuery<"document">, id: string): DocumentElement | undefined;
    /** Inspect a range within one paragraph. */
    range(selection: import("../foundation/index.js").DocumentSelection): DocumentTextRange;
    ranges(): readonly DocumentTextRange[];
    /** Convert all query results into one contiguous editable range. Does not read or change the editor selection. */
    toSelection(): import("../foundation/index.js").DocumentSelection;
    within<T extends DocumentElement>(element: T | readonly T[]): DocumentQuery<T["kind"]>;
    closest<T extends DocumentElementKind>(kind: T): DocumentQuery<T>;
    where(filter: DocumentFilter<K>): DocumentQuery<K>;
    filter(predicate: (element: ElementOf<K>) => boolean): DocumentQuery<K>;
    children(): DocumentQuery;
    descendants(): DocumentQuery;
    /** All descendant paragraphs, including table cells. */
    paragraphs(): DocumentQuery<"paragraph">;
    runs(): DocumentQuery<"run">;
    images(): DocumentQuery<"image">;
    tables(): DocumentQuery<"table">;
    rows(this: DocumentQuery<"table">): DocumentQuery<"row">;
    cells(this: DocumentQuery<"table"> | DocumentQuery<"row">): DocumentQuery<"cell">;
    contentControls(): DocumentQuery<"contentControl">;
    bookmarks(): DocumentQuery<"bookmark">;
    stories(this: DocumentQuery<"document">): DocumentQuery<"story">;
    findText(text: string | RegExp): QueryResults<DocumentTextRange>;
}

Selections and ranges

Selection offsets use UTF-16 text positions and the end is exclusive. Page indices are zero based. Content can cross stories; use separate ranges for noncontiguous scopes. Authored paragraph measurements use points; rendered geometry uses twips.

Import from @onodocs/sdk.

DocumentSelection
export interface DocumentSelection {
    readonly start: ParagraphPosition;
    readonly end: ParagraphPosition;
}

Edits and observed results
