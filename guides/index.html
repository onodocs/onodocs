Build a DOCX viewer

The JavaScript and TypeScript DOCX viewer guide includes a live demo and source code for opening local files, showing progress, cancelling a load, and selecting text.

Install

The SDK processes documents in the browser or Node.js. Canvas provides the browser viewer, page painting, selection and HTML attachments.

npm install @onodocs/sdk @onodocs/canvas

SDK on npm · Canvas on npm · Release archives

Install matching versions. A backend doing analysis or image/PDF export needs only the SDK. A frontend receiving prepared pages needs only Canvas. The public repository contains runnable JavaScript and TypeScript samples. Evaluation and commercial terms apply.

ImportPurpose

main.js

import { openDocument } from "@onodocs/sdk/browser";
import { createDocument } from "@onodocs/canvas";

const container = document.querySelector("#pages");
const statusElement = document.querySelector("#status");
const controller = new AbortController();
let doc, canvasDocument, view;

window.addEventListener("pagehide", event => {
  if (!event.persisted) {
    controller.abort();
    doc?.dispose();
  }
});

try {
  const response = await fetch("/sample.docx", { signal: controller.signal });
  if (!response.ok) throw new Error("Document is unavailable.");
  const bytes = await response.arrayBuffer();
  doc = await openDocument(bytes, { signal: controller.signal });
  canvasDocument = createDocument(doc);
  view = canvasDocument.mount(container, { zoom: "fit-width" });
  await view.whenRendered();
  statusElement.textContent = `${doc.pages.length} pages. Select text to copy it.`;
} catch (error) {
  doc?.dispose();
  if (!controller.signal.aborted) statusElement.textContent = error.message;
}

Pass a DOCX, DOCM, DOTX or DOTM File from a file input directly to openDocument. Macros are not executed. Give the container a usable width. fit-width follows resizing. The content-query, attachment, update and geometry snippets below use this doc, canvasDocument and view. Add those snippets inside the try block after await view.whenRendered().

Load large documents progressively

In main.js above, replace the three lines that open the document, create the Canvas document and mount the view with this block. Keep the fetching, error handling and cleanup around it.

doc = await openDocument(bytes, {
  signal: controller.signal,
  onProgress(progress) {
    canvasDocument ??= createDocument(progress.document, {
      container, viewOptions: { zoom: "fit-width" }
    });
    statusElement.textContent = `Loading… ${progress.document.pages.length} pages available`;
  }
});
view = canvasDocument.view;

Early pages can change as pagination settles. Opening resolves with the complete document. The complete viewer sample adds a file picker, a Cancel button and document replacement. Scrolling paints nearby pages and releases distant canvases, while document content and layout still consume memory proportional to document size.

Embed a license

Pass the license key issued by OnoDocs when opening a document. It can be included in your application bundle. Verification happens offline and requires HTTPS or localhost in a browser.

const doc = await openDocument(bytes, { licenseKey: "YOUR_SIGNED_LICENSE" });

Without a key, the SDK runs in non-production evaluation mode with watermarked output. A trial key removes the watermark for 30 days. Commercial keys keep working indefinitely for covered SDK releases. Request a trial or choose a commercial license on the pricing page.

Extract text and tables

Follow the JavaScript and TypeScript DOCX extraction guide to read paragraphs, select tables by headers and export JSON in the browser or Node.js. The guide includes a live demo and complete sample source.

Inspect document content

const paragraphs = doc.query.paragraphs().all();
const dates = doc.query.contentControls().where({ tag: "delivery-date" }).all();
const matches = doc.query.findText("Client approval:").all();

Choose an element type, filter it, then select the results. Use one() when exactly one match is required, optional() for zero or one, and all() for every match.

Read a table

const table = doc.query.tables()
  .where({ headers: ["Deliverable", "Owner", "Due"] }).one();
const rows = table.textRows.slice(1);

textRows includes the header row, so slice(1) selects the data rows. Query again after updates to read current values.

Scope a query

const cells = doc.query.within(table).cells().all();
const headers = doc.query.stories().where({ story: "header" }).paragraphs().all();

Queries work independently of rendering. See query selectors and filters, document elements, and text ranges.

Attach HTML controls

Define ordinary controls in HTML, then anchor them to document content. This example uses the first delivery-date control in the supplied project brief.

<input id="delivery-date" aria-label="Delivery date">
<button id="submit">Submit</button>
const field = doc.query.contentControls().where({ tag: "delivery-date" }).first();
const input = document.querySelector("#delivery-date");
input.value = field.text;
view.attach(input, { anchor: doc.geometry.fragments(field)[0] });

view.attach(document.querySelector("#submit"), {
  anchor: doc.pages[0],
  placement: "inside-bottom-right", inset: 480,
  size: { width: 2400, height: 600 }
});

Placement, size, and spacing use document geometry. Your application handles the controls’ values and events. Content spanning multiple fragments needs an explicit fragment anchor; see attachment options.

The Custom form sample shows editable delivery dates, approval, and submission.

Update text and fill templates

Create a tagged content control in Word, then fill it with application data. For this example, open the booking template instead of sample.docx.

const customer = doc.query.contentControls().where({ tag: "customer" }).one();

await doc.update({ target: customer, text: "Willow Design" });

Updates refresh the rendered pages. Read queries and geometry again afterward, and reattach any HTML controls. The original file stays unchanged. Saving an updated Word file is not supported. See update targets and constraints.

Pages and coordinates

Zoom and render a page

view.setZoom(1.25);
view.setZoom("fit-width");

const canvas = document.createElement("canvas");

Page indices are zero based. Page coordinates use twips: 1440 units per inch.

const match = doc.query.findText(/approval/i).first();

Errors and cleanup

Handle rejected SDK promises in your application and check response.ok when fetching documents. Pass an AbortSignal to cancel work when the source changes or the component disappears. Release browser documents when no longer needed. This also removes their views and attachments. Analysis-only documents need no disposal.

This shared application helper handles fetching, errors, cancellation, and cleanup. It is included in every framework project below as examples/sdk/mount.ts. The third argument handles errors and the fourth receives loading status.

Shared mount helper
import type { BrowserDocument } from "@onodocs/sdk/browser";
import type { CanvasDocument } from "@onodocs/canvas";

export function mountDocument(container: HTMLElement, source: string | File, onError: (error: unknown) => void = console.error, onStatus: (status: string) => void = () => {}) {
  const controller = new AbortController();
  let document: BrowserDocument | undefined;
  let canvasDocument: CanvasDocument | undefined;
  onStatus("Opening document…");
  void (async () => {
    try {
      const [{ openDocument }, { createDocument }] = await Promise.all([import("@onodocs/sdk/browser"), import("@onodocs/canvas")]);
      controller.signal.throwIfAborted();
      let input: File | ArrayBuffer;
      if (typeof source === "string") {
        const response = await fetch(source, { signal: controller.signal, credentials: "same-origin" });
        if (!response.ok) throw new Error(`Document request failed (${response.status})`);
        input = await response.arrayBuffer();
      } else input = source;
      document = await openDocument(input, { signal: controller.signal, onProgress(progress) {
        if (controller.signal.aborted) return;
        canvasDocument ??= createDocument(progress.document, { container, viewOptions: { zoom: "fit-width" } });
        onStatus(`Loading… ${progress.document.pages.length} pages available`);
      } });
      if (controller.signal.aborted) { document.dispose(); return; }
      await canvasDocument!.view!.whenRendered();
      if (!controller.signal.aborted) onStatus(`Ready. ${document.pages.length} pages. Select text to copy it.`);
    } catch (error) {
      canvasDocument?.dispose();
      document?.dispose();
      if (!controller.signal.aborted) onError(error);
    }
  })();
  return () => { controller.abort(); canvasDocument?.dispose(); document?.dispose(); };
}

const stop = mountDocument(container, "/sample.docx", console.error, console.log);

Call the returned stop() when replacing the document or removing its container. Framework examples connect this to their lifecycle hooks. For server rendering, dispose documents in finally, and dispose the renderer when the service or job ends. The server example below includes this cleanup.

next/app/page.tsx
"use client";
import { useEffect, useRef, useState } from "react";
import { mountDocument } from "../../../sdk/mount";

function Viewer({ source }: { source: string | File }) {
  const host = useRef<HTMLDivElement>(null);
  const stop = useRef(() => {});
  const [status, setStatus] = useState("Opening document…");
  useEffect(() => {
    const dispose = mountDocument(host.current!, source, error => setStatus(String(error)), setStatus);
    stop.current = dispose;
    return dispose;
  }, [source]);
  return <section>
    <button type="button" onClick={() => { stop.current(); setStatus("Loading cancelled. Open another document to continue."); }}>Cancel loading</button>
    <output role="status">{status}</output>
    <div className="viewport"><div ref={host} className="pages" /></div>
  </section>;
}

export default function Page() {
  const [document, setDocument] = useState<{ source: string | File; revision: number }>({ source: "/sample.docx", revision: 0 });
  const [visible, setVisible] = useState(true);
  function open(source: string | File) { setDocument(previous => ({ source, revision: previous.revision + 1 })); setVisible(true); }
  return <main>
    <h1>Word document viewer</h1>
    <p>Open a local Word file or the included sample. Selected files stay in your browser.</p>
    <a href="https://github.com/onodocs/onodocs/tree/main/examples/frameworks/next">Source on GitHub</a>
    <div className="toolbar">
      <label>Open Word file <input type="file" accept=".docx,.docm,.dotx,.dotm" onChange={event => { const file = event.currentTarget.files?.[0]; event.currentTarget.value = ""; if (file) open(file); }} /></label>
      <button type="button" onClick={() => open('/sample.docx')}>Open sample</button>
      <button type="button" onClick={() => setVisible(!visible)}>{visible ? "Hide viewer" : "Show viewer"}</button>
    </div>
    {visible && <Viewer key={document.revision} source={document.source} />}
  </main>;
}

<script setup lang="ts">
import { ref, onMounted, onUnmounted, watch } from "vue";
import { mountDocument } from "../../sdk/mount";

const props = defineProps<{ source: string | File }>();
const host = ref<HTMLElement>();
const status = ref("Opening document…");
let stop = () => {};
let unwatch: (() => void) | undefined;
onMounted(() => {
  unwatch = watch(() => props.source, source => {
    stop();
    stop = mountDocument(host.value!, source, error => { status.value = String(error); }, value => { status.value = value; });
  }, { immediate: true });
});
onUnmounted(() => { unwatch?.(); stop(); });
function cancel() { stop(); status.value = "Loading cancelled. Open another document to continue."; }
</script>
<template>
  <button type="button" @click="cancel">Cancel loading</button>
  <output role="status">{{ status }}</output>

</template>

angular/main.ts
import { bootstrapApplication } from "@angular/platform-browser";
import { Component, ElementRef, DestroyRef, afterNextRender, inject, input, signal, viewChild } from "@angular/core";
import { mountDocument } from "../../sdk/mount";

@Component({ selector: "document-viewer", template: `<button type="button" (click)="cancel()">Cancel loading</button><output role="status">{{ status() }}</output><div class="viewport"><div #host class="pages"></div></div>` })
class DocumentViewer {
  source = input.required<string | File>();
  host = viewChild.required<ElementRef<HTMLElement>>("host");
  status = signal("Opening document…");
  private _stop = () => {};
  constructor() {
    const destroy = inject(DestroyRef);
    afterNextRender(() => {
      this._stop = mountDocument(this.host().nativeElement, this.source(), error => this.status.set(String(error)), value => this.status.set(value));
    });
    destroy.onDestroy(() => this._stop());
  }
  cancel() { this._stop(); this.status.set("Loading cancelled. Open another document to continue."); }
}

@Component({ selector: "app-root", imports: [DocumentViewer], template: `
  <main><h1>Word document viewer</h1>
  <p>Open a local Word file or the included sample. Selected files stay in your browser.</p>
  <a href="https://github.com/onodocs/onodocs/tree/main/examples/frameworks/angular">Source on GitHub</a>
  <div class="toolbar">
    <label>Open Word file <input type="file" accept=".docx,.docm,.dotx,.dotm" (change)="choose($event)"></label>
    <button type="button" (click)="open('/sample.docx')">Open sample</button>
    <button type="button" (click)="visible.set(!visible())">{{ visible() ? 'Hide viewer' : 'Show viewer' }}</button>
  </div>
  @if (visible()) { @for (entry of documents(); track entry) { <document-viewer [source]="entry.source" /> } }
  </main>` })
class App {
  visible = signal(true);
  documents = signal([{ source: "/sample.docx" as string | File }]);
  open(source: string | File) { this.documents.set([{ source }]); this.visible.set(true); }
  choose(event: Event) {
    const input = event.target as HTMLInputElement;
    const file = input.files?.[0];
    input.value = "";
    if (file) this.open(file);
  }
}
bootstrapApplication(App).catch(console.error);

    private ElementReference _host;
    private IJSObjectReference? _module;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (!firstRender) return;
        var module = await JS.InvokeAsync<IJSObjectReference>("import", "/viewer.js");
        if (_disposed) { await module.DisposeAsync(); return; }

        await module.InvokeVoidAsync("mount", _host);

        _disposed = true;
        if (_module is null) return;

Shared browser controls for Razor Pages and Blazor
import { mountDocument } from "../sdk/mount";

export function mount(host: HTMLElement) {
  const pages = host.querySelector<HTMLElement>(".pages")!;
  const status = host.querySelector<HTMLOutputElement>("output")!;
  const events = new AbortController();
  const options = { signal: events.signal };
  let stop = () => {};
  function open(source: string | File) {
    stop();
    stop = mountDocument(pages, source, error => { status.textContent = String(error); }, value => { status.textContent = value; });
  }
  host.querySelector<HTMLInputElement>('input[type="file"]')!.addEventListener("change", event => {
    const input = event.target as HTMLInputElement;
    const file = input.files?.[0];
    input.value = "";
    if (file) open(file);
  }, options);
  host.querySelector("[data-open]")!.addEventListener("click", () => open("/sample.docx"), options);
  host.querySelector("[data-cancel]")!.addEventListener("click", () => { stop(); status.textContent = "Loading cancelled. Open another document to continue."; }, options);
  const observer = new MutationObserver(() => { if (!host.isConnected) dispose(); });
  observer.observe(document.body, { childList: true, subtree: true });
  function dispose() { stop(); events.abort(); observer.disconnect(); }
  window.addEventListener("pagehide", event => { if (!event.persisted) dispose(); }, options);
  open("/sample.docx");
}

Define the endpoints

server.mjs serves the frontend and two document endpoints from one origin. GET /document returns the page list; GET /document/pages/0 returns the first page. Page numbers start at zero. The SDK prepares the response bodies when you request format: "json".

import { createServer } from "node:http";
import { readFile } from "node:fs/promises";
import { build } from "esbuild";
import { createRenderer } from "@onodocs/sdk/server";

const directory = import.meta.dirname;
const html = await readFile(new URL("./index.html", import.meta.url));
const client = await build({ absWorkingDir: directory, entryPoints: ["client.js"], bundle: true, format: "esm", platform: "browser", write: false });
const renderer = await createRenderer({ channel: "chrome" });
try {
  const input = process.argv[2] ?? new URL("./sample.docx", import.meta.url);
  const doc = await renderer.openDocument(await readFile(input));
  const server = createServer(async (request, response) => {
    try {
      if (request.method !== "GET") {
        response.writeHead(405, { Allow: "GET" }).end();
        return;
      }
      const path = new URL(request.url, "http://localhost").pathname;
      let body, type;
      if (path === "/") {
        body = html;
        type = "text/html; charset=utf-8";
      } else if (path === "/client.js") {
        body = client.outputFiles[0].contents;
        type = "text/javascript; charset=utf-8";
      } else if (path === "/document") {
        body = await doc.manifest({ format: "json" });
        type = "application/json";
      } else {
        const match = /^\/document\/pages\/(\d+)$/.exec(path);
        const index = match ? Number(match[1]) : -1;
        if (!Number.isSafeInteger(index) || index < 0 || index >= doc.pages.length) {
          response.writeHead(404).end("Not found");
          return;
        }
        body = await doc.page(index, { format: "json" });
        type = "application/json";
      }
      response.writeHead(200, { "Content-Type": type, "Cache-Control": "no-store" });
      response.end(body);
    } catch (error) {
      console.error(error);
      response.writeHead(500).end("Unable to load the document.");
    }
  });
  const port = Number(process.env.PORT ?? 5175);
  await new Promise((resolve, reject) => {
    server.once("error", reject);
    server.listen(port, "127.0.0.1", resolve);
  });
  console.log(`Backend viewer: http://127.0.0.1:${server.address().port}`);
  await new Promise(resolve => {
    process.once("SIGINT", resolve);
    process.once("SIGTERM", resolve);
  });
  server.closeAllConnections();
  await new Promise(resolve => server.close(resolve));
} finally {
  await renderer.dispose();
}

Open the document in the frontend

client.js opens the document URL. Canvas loads the page list and requests pages as they become visible.

import { openDocument } from "@onodocs/canvas";

const status = document.querySelector("#status");
let doc;
try {
  doc = await openDocument("/document", {
    container: document.querySelector("#pages"),
    viewOptions: { zoom: "fit-width" }
  });
  window.addEventListener("pagehide", event => { if (!event.persisted) doc.dispose(); });
  await doc.view.whenRendered();
  status.textContent = `${doc.pages.length} pages. Select text to copy it.`;
} catch (error) {
  doc?.dispose();
  status.textContent = error.message;
}

The sample includes its package configuration and document. To use these files in a new project, install @onodocs/sdk, @onodocs/canvas and esbuild, then put a sample.docx beside them and run node server.mjs. Use matching SDK and Canvas releases.

Use it in your application

The sample listens only on your computer. In production, apply your application's document authorization to both endpoints. Same-origin session cookies work with the default client. For bearer tokens or cross-origin cookies, pass request: { headers, credentials } to Canvas openDocument; those options apply to the page list and every page request.

Keep the server document open while its endpoints are in use. For changing documents, give each completed version its own URL and reopen the frontend view after an update. Dispose the previous Canvas document. This keeps the page list and page content from different versions separate.

The original DOCX stays on the backend; the frontend receives the content needed to display and select its pages. Supply font files for consistent results across hosts, or ensure the required fonts are installed on both machines. See server options and Canvas options.

Fonts and deployment

Fonts affect line breaks and page count. Embedded document fonts load automatically. Provide additional fonts to match your documents.

const doc = await openDocument(file, {
  fonts: { "Example Sans": "/fonts/example-sans.woff2" }
});

Use licensed font URLs in the browser. Server document contexts make no outbound requests, so supply data URLs or install fonts on the rendering host. For offline use, keep scripts, documents, and fonts local.

Use the same browser version and fonts for consistent output. Import @onodocs/sdk/browser in browser bundles to keep server dependencies out. All entry points include TypeScript declarations.
