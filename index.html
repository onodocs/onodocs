Automation and application extensions

  • Text and table extraction: compare the document with its extracted output. Browser and Node.js source.
  • Scripted report review: follow supporting passages and apply sample suggestions. This sample makes no AI calls.
  • Collaboration setup: start a local service and try editing with separate users.
  • Document modes: configure viewing, editing, review and form filling.

Focused developer examples

  • TypeScript viewer, JavaScript viewer and React viewer: loading, cancellation, replacement and cleanup.
  • Canvas viewer and export, HTML attachments and Tagged text replacement: individual public API examples.
  • Document queries: inspect tables and the document tree, export ASCII and simulate an email draft.
  • Framework applications and backend processing with frontend display: complete integration projects with their own servers.
