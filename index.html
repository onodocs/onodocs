OnoDocs samples

Render Word documents, add application controls, fill tagged fields, and inspect document structure.

  • TypeScript DOCX viewer — the complete first guide sample.
  • JavaScript DOCX viewer — the same sample in plain JavaScript.
  • React and TypeScript Word viewer — loading, cancellation, replacement and unmount cleanup.
  • Viewer — open a document, select text, and export PNG or PDF.
  • Custom form — attach HTML inputs and collect values.
  • Template — fill a booking confirmation.
  • Document workflows — tables, ASCII, document tree, and a simulated email draft.
  • TypeScript text and table extraction — local text and JSON, with copy and download.
  • JavaScript text and table extraction — the same sample in plain JavaScript.

These examples run locally in evaluation mode. The SDK adds an evaluation watermark. Selected documents stay in your browser.
