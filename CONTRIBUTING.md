# Contributing and support

Start with [running the samples](docs/samples.md). Report reproducible bugs and
feature requests through GitHub Issues. Include the SDK version, browser or
Node.js version, operating system, expected behavior and reproduction steps.
For rendering issues, compare the same document in Word or LibreOffice and
provide a minimal document using fictional data.

Do not post private documents, customer data, license keys or credentials.
Use the [support page](https://onodocs.com/support/) for private reports,
commercial support, billing and trial requests. The website is the canonical
API documentation.

Changes should use the exported SDK APIs. This repository does not contain the
rendering engine. Run `npm run typecheck`, `npm run build` and the affected
sample before proposing changes. Contributions are licensed under LICENSE.
